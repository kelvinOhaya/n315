# Sass & BEM Methodology Project

## Project Overview

This project is designed to teach modern CSS architecture and best practices through the implementation of **Sass** (Syntactically Awesome StyleSheets) and the **BEM** (Block, Element, Modifier) naming methodology. By completing this assignment, you will gain hands-on experience with CSS preprocessing, modular styling, and scalable CSS organization patterns that are essential for professional front-end development.

## Introduction

For this assignment, you will need to know about Sass. I also want you to read about the BEM (Block, Element, Modifier), which uses SASS, and you can find the link [here](https://css-tricks.com/bem-101/). You can also research this topic elsewhere. I just picked this article. You will also need to do Homework 1.

## Learning Objectives

The objectives are to learn about the BEM methodology and understand how this can benefit your styling pages. Specifically, you will:

- Understand the principles and advantages of using Sass for CSS preprocessing
- Learn the BEM naming convention and how it promotes maintainable, scalable CSS
- Implement BEM methodology in a real project structure
- Organize stylesheets using Sass modules and partials
- Apply best practices for naming conventions and component-based styling
