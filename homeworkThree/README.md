# Homework 3: Why You Should Watch RE:ZERO

A five-page, dynamically rendered website introducing reasons to watch _RE:ZERO_. The site uses a model-view-controller (MVC) structure and includes images, text, and an embedded music player.

## Pages

- **Home** — Introduction to the site
- **Reason #1** — World building
- **Reason #2** — Side characters
- **Reason #3** — Ratings
- **Conclusion** — Closing message and embedded music

- [Live website](https://in-info-web4.luddy.indianapolis.iu.edu/~kelohaya/homeworkThree/)

## Run locally

Open `index.html` in a browser or use a local development server. Styles are linked from `css/styles.css`, and the application entry point is `scripts/app/app.js`.
