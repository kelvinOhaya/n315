# Homework 7

**Live site:** [https://in-info-web4.luddy.indianapolis.iu.edu/~kelohaya/homework7/](https://in-info-web4.luddy.indianapolis.iu.edu/~kelohaya/homework7/)

Homework 7 is a front-end class project that builds on the Jungle Cook recipe site, adding Firebase-backed features such as authentication and data storage. It includes a landing page, a browse page, a recipe creation page, and login/sign-up forms.

## Built with

- JavaScript modules
- Vite
- Sass
- Firebase
- HTML and CSS

## Run locally

Install dependencies and start the Vite development server:

```sh
npm install
npm run dev
```

## Build and publish

Create a production build with:

```sh
npm run build
```

Vite writes the static site to `dist/`. To publish through FTP, upload the **contents** of `dist/` to the directory served by the web host.
